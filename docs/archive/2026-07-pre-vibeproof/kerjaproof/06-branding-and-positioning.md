# Branding and Positioning

## Recommended brand

**KerjaProof**

“Kerja” gives the product a Malaysian identity, while “Proof” communicates evidence of capability rather than résumé claims.

## Primary tagline

> See capability in action.

## Vibe-coding sub-brand tagline

> AI can generate code. Can you own it?

## Product description

> KerjaProof helps Malaysian SMEs evaluate software engineers through realistic AI-assisted engineering tasks. Candidates must understand, verify, debug, test, and take responsibility for the code they ship.

## Brand voice

- Trustworthy
- Practical
- Evidence-led
- Human-centered
- Responsible
- Future-oriented

## Product naming system

- Product: **KerjaProof**
- Assessment: **Patch & Ship**
- Candidate workspace: **Engineering Mission**
- Evidence view: **Decision Timeline**
- Employer output: **Capability Profile**
- AI review feature: **Evidence Assistant**

## Positioning against existing tools

| Typical hiring method | KerjaProof |
|---|---|
| Screens résumé keywords | Observes engineering decisions |
| Takes code submissions at face value | Tests understanding and verification |
| Penalizes or hides AI use | Allows AI and measures responsible use |
| Produces opaque scores | Shows evidence from actions |
| Focuses on abstract algorithms | Simulates real engineering work |
| Automatically filters candidates | Supports human review |

## Brand promise

> KerjaProof helps employers see whether a candidate can own the outcome—not just produce an impressive-looking artifact.

## What makes KerjaProof stand out

1. It focuses on behavior rather than résumé claims.
2. It evaluates modern AI-assisted engineering instead of pretending AI does not exist.
3. It shows transparent evidence rather than a black-box hiring score.
4. It is designed for Malaysian SMEs and can support English and Bahasa Melayu.
5. It keeps a human in the decision loop.
