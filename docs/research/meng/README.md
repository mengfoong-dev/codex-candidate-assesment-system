# KerjaProof Research and Product Findings

This folder consolidates the research, product direction, branding, assessment design, and hackathon execution findings for the candidate capability assessment project.

## Recommended product

**KerjaProof: Vibe-to-Production Challenge**

KerjaProof places software-engineering candidates in a realistic AI-assisted development incident and observes whether they can understand, verify, debug, test, and take ownership of AI-generated code.

## Core positioning

> AI can generate code. Can you own it?

## Current direction note

The numbered research files preserve the earlier `KerjaProof` exploration. The latest debate and product decisions use the `VibeProof` brand and an artifact-grounded ownership-verification approach. When the documents conflict, use the [ideas and debate record](ideas/README.md) as the current decision source.

## Important limitation

This is a research-informed hackathon prototype, not a validated psychometric hiring test. It should produce transparent evidence for human review rather than automatic hiring or rejection decisions.
